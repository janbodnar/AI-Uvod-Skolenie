# Klávesové skratky pre slovenskú klávesnicu

22. 10. 2026

Prehľad najpoužívanejších skratiek pre Windows so slovenským rozložením QWERTZ, vrátane písania špeciálnych znakov cez AltGr.

## Ako funguje slovenská klávesnica

- **Rozloženie QWERTZ:** písmená Y a Z sú oproti anglickej klávesnici vymenené.
- **Horný rad:** bez Shiftu píše diakritiku (+ ľ š č ť ž ý á í é), so Shiftom číslice 1–0.
- **AltGr** (pravý Alt, alebo Ctrl + ľavý Alt): sprístupňuje znaky ako @, #, {, }, [, ], €.
- Skratky typu Ctrl + písmeno fungujú rovnako ako na anglickej klávesnici, len Ctrl + Z a Ctrl + Y sú na iných miestach.

## Špeciálne znaky cez AltGr

AltGr je pravý Alt; ak ho klávesnica nemá, použite Ctrl + ľavý Alt.

| Znak | Skratka | Použitie |
| --- | --- | --- |
| @ | AltGr + V | E-mailové adresy |
| # | AltGr + X | Hashtagy, čísla |
| & | AltGr + C | „A“ v názvoch firiem |
| $ | AltGr + ô | Doláre, programovanie |
| € | AltGr + E | Eurá |
| \ | AltGr + Q | Cesty k súborom vo Windows |
| \| | AltGr + W | Programovanie |
| [ ] | AltGr + F / AltGr + G | Hranaté zátvorky |
| { } | AltGr + B / AltGr + N | Zložené zátvorky |
| < > | AltGr + , / AltGr + . | Menší / väčší ako |
| * | AltGr + - | Násobenie (alebo * na numerickej klávesnici) |
| ~ | AltGr + 1 | Vlnovka |
| ^ | AltGr + 3, potom medzerník | Mocnina, striezka |
| ° | AltGr + 5 | Stupne |
| ` | AltGr + 7, potom medzerník | Spätný apostrof |
| ÷ × | AltGr + ú / AltGr + ä | Delenie, násobenie |

**Veľké písmená s diakritikou:** kláves vľavo od Backspace píše dĺžeň (´) a so Shiftom mäkčeň (ˇ). Pre Á stlačte ´, potom Shift + A; pre Č stlačte Shift + ˇ, potom Shift + C. Rýchlejšie je zapnúť Caps Lock a stlačiť kláves č priamo.

Znaky, ktoré sa nevypíšu hneď (^, `, ´, ˇ), sú takzvané mŕtve klávesy: čakajú na ďalší znak, preto po nich stlačte medzerník.

## Tipy a časté problémy

- **Namiesto Z sa píše Y (a naopak):** je zapnuté anglické rozloženie. Prepnite ho cez Win + medzerník.
- **Namiesto ľščťž sa píšu číslice:** opačný problém, tiež zlý jazyk klávesnice. Aktuálny jazyk vidíte vpravo dole na paneli úloh (SK / ENG).
- **Číslice bez Shiftu:** použite numerickú klávesnicu so zapnutým Num Lock.
- **Heslá:** pri zadávaní hesla skontrolujte jazyk klávesnice, inak bude Y/Z alebo číslice vyzerať inak, než ste chceli.
- **AltGr nefunguje:** na niektorých notebookoch ho nahradí Ctrl + ľavý Alt.
